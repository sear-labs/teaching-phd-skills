# M2 — Reproducible Code

**Tier:** Year 1

The milestone that prevents *"I cannot reproduce my own Chapter 3."* All four are performed on
your actual dissertation repository — not a sample, not a copy.

The test at the end of this milestone is not a file listing. It is that **another student ran
your code on their machine and got your number.**

## The four skills

| Skill | Channel | Turn in as |
|---|---|---|
| Git and GitHub | arithmetic | repo URL + git check-ignore -v output |
| Code folder structure | arithmetic | repo URL + what-moved paragraph |
| Reproducible environments | arithmetic | repo URL + partner's signed run log |
| CLI agents and Claude Code | arithmetic | transcript excerpt + accepted diff |

### Order — this one is not optional

**Git and GitHub comes first.** Git history is permanent, and a credential committed once is
compromised regardless of what you do next. It is the only thing in the entire twenty-four-skill
curriculum that cannot be undone afterwards. Do not restructure a repo, run an agent on it, or
hand it to a partner before the `.gitignore` is written and verified.

### Pairing

**Reproducible environments** requires a partner from this class. Arrange it early — your partner
needs an hour on their own machine, and the skill cannot be completed alone.

## How you turn this in

**Nothing new gets made for this.** All four skills were already submitted as ordinary
weekly log entries, each one replacing that week's WR, WW or WA. This submission just tells me
where to find them.

**Paste this straight into the text box of this assignment.** No attachment is needed — the
artifacts are already sitting in the weekly entries you link to.

One line per skill: the skill, which entry it went in, the week, and where the artifact is.

```
Git and GitHub              WA3   week of 8 Sep   github.com/you/thesis
Code folder structure       WA5   week of 22 Sep  same repo, see README
Reproducible environments   WA7   week of 6 Oct   attached to that entry
CLI agents and Claude Code  WA9   week of 20 Oct  Overleaf link in that entry
```

Then **one paragraph, 150 words maximum**: which of the four was hardest, and why. Not
what you did — you already wrote that. What was hard about it.

That is the whole submission. It should take ten minutes.

### How it is graded

**Complete / redo.** Redo means one or more competency checks did not pass. I will name which
skill and which check, and **you redo only that skill** — not the milestone, and not the others.
A milestone marked complete is complete permanently; it does not repeat in a later semester.

### Where to check what each skill needed

[**The whole curriculum on one page**](https://sear-labs.github.io/teaching-phd-skills/handbook/curriculum.html) — every skill with the exact artifact it wanted
and the checklist it was graded against. Use it to confirm you have everything before submitting.
